# mdplayer.driver.pmd

pmd driver

| type    | setting              | default | chip   |
|---------|----------------------|:-------:|--------|
| PPC/PVI | `Pmd#soundboard=1`   |  ✔ *1   | Ym2608 |
| P86     | `Pmd#soundboard=2`   |   *1    | P86    |
| PPS     | `Pmd#usePPSDRV=true` |    ✔    | PPS    |
| PPZ     | `Pmd#usePPZ8=ture`   |    ✔    | PPZ8   |

*1 ... as for sound board, auto-detection is default
